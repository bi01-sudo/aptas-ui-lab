# Aptas Invest — Design Lab (site publicado, temporário)

Este repositório contém **apenas o site já montado** do protótipo de refatoração
de UX/UI do Aptas Invest. Nenhum código-fonte.

🔗 **https://bi01-sudo.github.io/aptas-ui-lab/ui-lab/**

Publicação **temporária**, compartilhada por link direto e marcada como
não-indexável (`robots.txt` + `noindex`). Será despublicada após a revisão.

Todos os fundos, CNPJs, gestores, administradores, séries de cotas, curvas de
juros, notícias e saldos são **fictícios** e existem apenas para validar a
interface. Nada aqui é recomendação de investimento.
