# Aptas Invest — Design Lab (site publicado)

Este repositório contém **apenas o site já montado** do protótipo de refatoração
de UX/UI do Aptas Invest, publicado via GitHub Pages.

👉 **https://bi01-sudo.github.io/aptas-ui-lab/ui-lab/**

Todos os fundos, CNPJs, gestores, administradores, séries de cotas, curvas de
juros, notícias e saldos exibidos são **fictícios** e existem apenas para validar
a interface. Nada aqui é recomendação de investimento.

O código-fonte fica em um repositório separado e privado.
